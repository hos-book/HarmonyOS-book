# v0.1.73 更新日志

一、漫画阅读
新增本地 AI 上色和端侧漫画翻译，支持恢复原图；优化图片逐张加载、连续跨章阅读、预缓存、失败重试与缓存恢复，减少重复处理。完善漫画设置、音量键翻页和逐图状态提示，优化超分处理及内存占用。

二、本地导入
新增 PDF 导入，保留原版页面，支持缩放、翻页和阅读进度恢复。完善 EPUB 电子书与漫画自动识别、本地漫画切换、封面提取及缓存；优化从系统文件管理器打开文件的导入流程。

三、边听边读
支持长按正文“从本段朗读”，手动翻页后朗读跟随新页面，朗读时自动翻页；修复跨页长段落跟读、连续朗读与暂停后翻页的问题。本章朗读进度支持拖动或点击跳转，自定义音色支持单独启用、停用，优化正文高亮和播放位置同步。

四、日常体验
新增紧凑“继续阅读”桌面卡片及阅听记录“简听一语”古诗词摘句。优化墨山主题、主题套装预览、阅读菜单与阅听统计胶囊的沉浸效果，改进页面切换、列表和提示文案。

五、书源与稳定性
优化导入书源的解析、图片处理和网络兼容性；书源导入数量对所有用户开放。改进缓存管理、异常提示及阅读恢复体验。

六、会员服务
新增月度、年度和终身会员购买及权益对比，支持终身会员限时优惠；完善权益查询、恢复购买、订阅管理及返回应用后的权益刷新。月度6元、年度60元；终身原价120元，活动价60元，活动截至2026年12月25日，实际价格与权益以购买页面为准。
