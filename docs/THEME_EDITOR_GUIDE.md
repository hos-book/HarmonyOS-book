# 简听主题制作说明书

本说明适用于 App、网页和 Windows 主题制作器。三端使用 `.jttheme` 文件交换整套主题，内容包括浅深配色、页面背景、底部 Tab、功能图标、默认书封、材质及播放器背景。阅读器和桌面应用图标沿用各自的设置。

交给 AI 制作主题时，使用 [主题 AI 制作规范](THEME_AI_GUIDE.md)。该文件可单独发送，包含可复制提示词、全部 112 个字段、素材约定与打包方法。

**打开制作器**

| 版本 | 入口 |
| --- | --- |
| App | 我的 → 主题与背景 → 套装 → 制作主题 |
| Windows | 双击 `D:\HSDA\tools\theme-editor\release\JianTing-Theme-Editor-1.0.0.exe` |
| 本机网页 | 在这台电脑的浏览器打开 http://127.0.0.1:5173/ |

网页地址由本机服务提供，服务运行期间可访问。重新启动时，在终端执行：

```powershell
cd D:\HSDA\tools\theme-editor
npm run dev -- --port 5173 --strictPort
```

公网地址需要将网页构建产物部署到网站后提供。

**制作一套主题**

1. 打开“主题信息”，填写主题名称与说明，选择材质强度和竖向底栏样式。App 从当前套装创建草稿；也可点开某个内置套装的预览，再选“制作主题”。网页和 Windows 首次打开时使用默认草稿。
2. 先选择“浅色”，依次调整配色、背景与图标；随后切到“深色”，单独配置夜间效果。两份配置随同一个主题文件保存。
3. 在“页面背景”中先编辑“通用”。首页、书架、记录和我的可选择“跟随通用”，也可各自配置纯色或图片。
4. 打开“底部 Tab”，分别为首页、书架、记录和我的设置常态图片与选中图片，再设置常态颜色和选中颜色。图片本身保留原色，状态颜色用于文字和系统符号。
5. 打开“播放器”，选择跟随书封、纯色或图片，并调整该模式下显示的参数。
6. 切换预览中的首页、书架、记录、我的和播放器，查看各页面的整体效果。网页和 Windows 可点击预览中的文字、图标或书封，定位对应编辑项。

网页和 Windows 在宽窗口并列显示浅深预览，窄窗口显示当前模式。App 提供浅深切换预览；宽窗口左右排列预览与编辑区，窄窗口上下排列。

**各组编辑项**

| 分组 | 主要内容 |
| --- | --- |
| 主题信息 | 名称、说明、材质强度、竖向底栏样式 |
| 配色 | 页面与卡片底色、主次文字、图标、主题色、控件、渐变、描边与阴影 |
| 页面背景 | 通用与四个主页面的背景模式、图片、底色、蒙层、模糊、焦点、缩放；我的账号卡图片与书封氛围开关 |
| 底部 Tab | 四项常态／选中图片，常态／选中颜色 |
| 功能图标 | 搜索、筛选、网格、列表、右箭头 |
| 书封装饰 | 在线书、本地书与播放器的默认封面；书名、作者及装饰配色；边框、书脊与书名排版 |
| 播放器 | 跟随当前书封、纯色、自选图片三种背景 |

页面背景选择“跟随基础套装”时使用基础主题效果；选择“跟随通用”时采用通用背景。选择图片后，可以调整水平位置、垂直位置和缩放来安排构图。蒙层用于提亮或压暗图片，模糊用于柔化背景。

播放器的跟随书封模式读取当前书籍封面，提供底色、模糊与蒙层；纯色模式提供底色与蒙层；图片模式另提供图片选择、焦点与缩放。播放器的播放控制与章节设置继续使用 App 原有功能。

网页和 Windows 图片选择支持 PNG、JPEG、WebP、SVG。App 从系统相册选择图片。Tab 图片适合使用带透明背景的素材；浅深模式可分别选择素材。颜色输入接受 `#RRGGBB` 与 `#AARRGGBB`，八位写法的前两位表示透明度，例如 `#80FFFFFF` 表示约半透明白色。

**保存、导出与手机应用**

1. 网页／Windows：点击右上角“导出”，保存得到 `主题名称.jttheme`。编辑内容随该文件保存，关闭编辑器前完成导出。
2. 将 `.jttheme` 文件传到手机，使用日常文件传输方式即可。
3. 手机：进入“我的 → 主题与背景 → 套装 → 制作主题”，打开“主题信息”，点击“导入主题”并选择文件。
4. 在 App 内查看浅深预览，再点击右上角“保存并应用”。保存与应用自制主题沿用现有会员权益。
5. App 制作的主题也可从“主题信息 → 导出”保存为 `.jttheme`，再由网页或 Windows 的“导入主题”打开。

分享时发送完整 `.jttheme` 文件即可，其中已经包含当前主题引用的素材。

**继续编辑已有主题**

App 在套装列表点开已保存的自制主题，选择“编辑主题”，修改后再次“保存并应用”。网页和 Windows 点击“导入主题”，选择之前导出的 `.jttheme`，编辑完成后再次导出。

网页预览用于查看配色、图片和布局关系，原生材质与实际书封效果以 App 显示为准。

完整字段与文件格式见 [主题钩子及包格式](THEME_BUNDLE_PLAN.md)，开发与构建方式见 [编辑器工程说明](../tools/theme-editor/README.md)。
