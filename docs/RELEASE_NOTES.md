# 1.1.10 更新日志（2026-11-17）

1. 新增书房式书架，以书籍分组和最近阅读卡片集中展示收藏，支持分组管理、添加书籍与拖动整理。
2. 书籍详情新增刷新入口，可更新作品信息和完整目录，并保留自定义展示、阅读进度及目录偏好；优化封面加载、展开与返回体验。
3. 优化播放器封面、字幕面板及横屏布局，改善后台返回后的进度校准、暂停续听与章节衔接；上下章切换遵循跳过片头设置。
4. 完善本地语音合成，支持导入兼容的 Piper、Kokoro 中文模型，为旁白和不同角色设置音色；优化连续朗读、音频预加载、音色切换和试听。
5. 完善 EPUB、HTML 文件排版，保留文件自带的字体、背景、分栏、表格和书内媒体，支持切换应用排版；修复部分 EPUB 章首标题重复显示的问题。
6. 丰富阅读主题及划词菜单设置，支持调整字体、段落、章节标题、页眉页脚的间距与颜色，以及划词操作的显示与排序；改善选词、复制、摘录和分享体验。
7. 提升 PDF 导入页面清晰度，单文件支持上限调整至 1 GiB，优化图片展示与放大阅读体验。
8. 优化漫画翻译的大图识别和译文定位，单页失败后可继续后续任务；完善漫画上色、跨页分割、四方向裁边及深浅色独立背景，支持按书设置翻页方式。
9. 完善已读与未读章节标记，优化章节切换、窗口变化后的阅读位置恢复与阅读时长记录。
10. 优化 App 背景、底部导航图标和会员页面，支持主页面共用或独立背景，并调整图片淡化、模糊、位置与缩放，改善不同窗口尺寸下的显示。
11. 优化全网榜单、作品匹配、封面加载与 AI 封面增强，完善阅读入口、返回定位以及迷你播放器常驻显示和闲置自动隐藏。
12. 修复部分设备搜索输入异常，完善搜索并发设置与净化规则管理，提升应用启动及日常操作的稳定性。
