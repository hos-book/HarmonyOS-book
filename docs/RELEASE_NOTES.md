# 1.0.4 更新日志（2026-11-03—2026-11-05）

1. 新增本地书籍全文搜索，支持跨章节查找并定位正文。
2. 完善同账号多设备同步，支持在线书架、阅听进度及历史记录同步。
3. 优化连续朗读与跨章节衔接，增加短段合成和下一章语音预准备，改善自定义音色加载与异常提示。
4. 升级音色管理，支持搜索、分组筛选、排序及批量管理，完善文件、链接和文本导入。
5. 新增电子书章节预加载设置，阅读与朗读共用正文缓存。
6. 完善朗读显示、对话高亮、字距和音量增幅设置，优化横屏双栏排版。
7. 播放栏支持跟手展开与收起，优化封面转场、后台恢复及桌面卡片播放控制。
8. 新增系统桌面歌词，支持展示有声书 AI 字幕和电子书朗读内容。
9. 优化 EPUB 导入、推荐榜单排序和书源兼容性。
10. 更新应用图标与启动动画，改善深浅色外观及不同设备的材质表现。

部分功能需会员或系统支持。跨设备同步需开启系统云同步及应用内同步开关，接收设备需导入相同书源，不同步本地文件与书源定义。EPUB 导入优化需重新导入书籍后生效。

7. 优化横屏双栏阅读及平板布局，改善正文宽度和两栏空间分配。

10. 优化底栏收展动画、封面位置和播放按钮样式，目录可在当前页面直接弹出；修复新旧底栏切换时的状态异常。
11. 优化沉浸光感材质的设备兼容性，完善部分设备的效果适配。
12. 精简阅读主题设置，自定义主题改为三列展示，并调整编辑入口。
13. 优化详情页、迷你播放器和阅听记录的封面转场，改善展开、返回及底部导航体验。
14. 新增流光彩色应用图标，修复字幕下载进度重复显示百分号等细节问题。
