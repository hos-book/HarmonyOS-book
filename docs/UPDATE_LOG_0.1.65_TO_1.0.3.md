# 简听阅读 v1.0.3 更新日志

对比版本：v0.1.65 → v1.0.3。

整理依据：v0.1.65 发布提交之后的 Git 记录，以及当前工作区的功能实现和产品文档。本文包含尚未提交的最新改动；发布前应以最终安装包实际包含的功能为准。本次仅整理日志，未重新执行构建或设备验收。

## 更新公告精简版

从 v0.1.65 到 v1.0.3，简听阅读带来了更丰富的阅听方式和更细致的个性化体验。

- 新增小说与漫画自动翻页、自动滚动，可调整速度，随时暂停或继续。
- 新增阅读书签、正文替换净化、长按从本段朗读，完善边听边读与朗读进度跳转。
- 新增漫画本地 AI 着色、端侧翻译，支持日译中、韩译中、英译中及中译英；优化超分清晰度与处理稳定性。
- 新增漫画双指缩放、整图适屏、拼接分页及页间重叠设置，长图阅读更灵活。
- 新增 PDF 导入，完善 EPUB 插图、原书目录识别和大文件导入体验。
- 新增纸感书房、雾蓝、墨山主题套装，支持自定义阅读主题名称、配色和背景图。
- 新增“简简陪伴”，支持点击表情互动、长按拖动及应用内跨页面陪伴。
- 新增音频自动恢复／共存播放设置。
- 完善搜索自动翻页、指定源搜索、书架分组、封面编辑与漫画阅读进度展示。
- 优化后台续播、朗读跨页衔接、漫画加载、缓存管理、列表滚动和页面切换。
- 完善会员中心、权益说明与离线使用教程，修复沉浸菜单、统计胶囊阴影、评分换算等问题。

部分 AI、主题和自动备份功能需有效会员；部分系统能力取决于设备支持。漫画翻译首次使用需下载语言资源，PDF 按原版页面阅读，不支持文字重排或朗读。

## 完整更新日志

### 一、小说阅读与文字朗读

- 新增阅读书签，可记录当前章节、正文位置及内容预览，在书签列表中快速跳转或删除，方便收藏精彩段落和回看重要内容。
- 新增正文替换与净化规则，支持普通文本和正则表达式，可选择仅对当前书籍或全部书籍生效，并支持编辑、启用、停用、删除和当前章预览。
- 替换净化同时用于阅读与朗读，书签和续读位置仍对应原文，修改规则后按原阅读位置重新排版，避免规则变化造成定位错乱。
- 新增长按正文“从本段朗读”，可直接留在阅读页开始连续朗读。
- 完善边听边读：朗读高亮与页面跟随联动，手动翻页、滚动后的朗读定位更合理，减少迟到回调将正文拉回旧位置的问题。
- 优化系统及自定义 HTTP 音色的跨页连续朗读，避免按页尾拆分自然语句，并提前准备后续语音片段。
- 新增朗读合成配置，支持单次 1–10 段、100–4000 字、5–120 秒网络超时、0–3 次失败重试及 1–4 路网络预合成并发，便于根据音色接口和网络情况调整。
- 优化短句合并与后续片段预合成，减少每个短句重新等待的问题；暂停、跳读和切换音色时清理旧任务，减少过期语音插入。
- 新增合成文本特殊字符过滤与读法替换，可用“原词=>读法”逐行配置，右侧留空表示跳过朗读；设置只作用于合成内容，保留阅读正文。
- 完善自定义 TTS 导入，兼容逐行请求头、嵌套 JSON 请求体及 Kokoro 语音接口配置。
- 文字书播放页支持拖动或点击本章朗读进度跳转，拖动时预览百分比，松手后定位到对应语音片段；播放中跳转继续播放，暂停时调整位置保持暂停。
- 暂停朗读后手动翻页或滚动，再次播放可从新位置继续；未移动正文则保留原暂停点。
- 新增小说定时自动翻页，默认每 10 秒翻页，可在 3–120 秒之间调整；滚动模式支持自动滚动，默认每分钟 20 行，可调节为每分钟 6–100 行。
- 自动阅读提供独立的暂停、继续与关闭按钮，暂停后可从当前位置恢复；触摸正文或呼出工具栏不直接关闭自动阅读，加载和选字期间临时等待。
- 自动阅读运行时临时保持亮屏，暂停或关闭后恢复原亮屏设置；切后台、离开页面或开启朗读时停止，重新进入后由用户手动开启。
- 优化仿真翻页行程、快速滑动衔接、连续滚动和字体或窗口变化后的阅读位置恢复。
- 完善阅读主题编辑，每套自定义主题可独立保存名称、文字与背景颜色、背景图和蒙层；背景支持自适应、平铺、拉伸和裁剪四种显示方式。
- 自定义主题编辑支持实时预览、导入、更换和移除背景图片，点击“保存并应用”后提交；免费可用 1 套，会员可用 5 套，额外主题在会员失效后保留数据。
- 优化状态栏、安全区、章节进度条及阅读工具栏的布局和颜色适配。

### 二、漫画阅读与 AI 功能

- 新增本地 AI 着色，可为黑白漫画生成彩色效果；着色与翻译独立控制，同时开启时先着色再绘制译文，关闭后恢复原图。
- 新增端侧漫画翻译，支持日文翻译中文、韩文翻译中文、英文翻译中文、中文翻译英文；图片和识别文字在本机处理。
- 翻译语言资源首次使用按方向下载，确认后展示下载进度并支持取消；下载完成自动开启，后续可复用已下载资源。
- 翻译菜单可直接选择四种翻译方向或关闭；切换方向会停止旧任务，避免不同语言结果混用，着色和翻译每次进入阅读时默认关闭。
- 优化漫画超分，修复部分图片错位、色块等异常，处理失败时保留原图。
- 新增直接双指捏合缩放，支持 1–4 倍就地放大，放大后单指拖动查看细节，缩回原大小后恢复正常滚动和翻页。
- 新增整图适屏，一张原图完整居中显示；同时保留原图宽度模式，方便按个人习惯选择整页浏览或纵向阅读。
- 新增拼接分页，将相邻图片连续排列，按视口高度翻页；可设置 0%、10%、20%、30% 页间重叠，默认 10%，便于衔接长图上下文。
- 拼接与连续模式保存图片序号及图内阅读位置，重新打开或窗口变化后尽量恢复到原位置。
- 完善连续滚动、左右翻页及渐隐阅读方式，长图可按屏阅读。
- 新增漫画定时自动翻页与自动滚动；自动翻页间隔可调为 3–120 秒，滚动速度可调为 6–120 vp/s，支持暂停、继续和关闭。
- 自动阅读适宽长图时先按屏读到底再换图，等待图片加载时不积累位移，减少加载完成后突然跳过内容的问题。
- 完善音量键翻页，漫画与小说分别保存设置。
- 漫画阅读模式、亮度、章节条等设置统一按漫画全局偏好保存。
- 本地导入漫画支持切回电子书阅读模式，并保留对应章节及图片位置。
- 漫画详情同步最新阅读进度，目录标记“正在阅读”，打开目录后自动定位当前章节，并提供“回到当前章节”入口；正序和倒序均按章节身份定位。
- 着色与翻译状态显示在对应图片上，整章解析显示等待时间。
- 优化图片预加载、解码尺寸、章节拼接和缓存保存，修复部分连续图片间的细缝，减少长章节加载和滑动开销。
- 优化漫画工具栏、章节条、翻译菜单及会员功能标识。

### 三、有声书播放与后台恢复

- 新增“音频播放方式”，可选择被其他音频打断后的自动恢复，或与其他应用共存播放；来电等中断仍遵循系统规则。
- 音频播放方式同时覆盖有声书与电子书朗读，方便在专注收听和多应用同时播放之间选择。
- 优化后台定时停止、耳机暂停、系统播控及音频打断后的播放位置保存。
- 修复部分场景返回前台显示旧进度、异步保存覆盖新位置等问题。
- 优化音频地址解析、播放衔接与文字朗读之间的音频控制协调。
- 优化暂停、定时结束后的已启用音频预缓存收尾，已配置的当前章及后续章节缓存可继续完成，减少再次收听时重复获取；关闭预缓存仍按关闭设置执行。
- 优化播放页封面加载、朗读段落展示及音色按钮状态反馈。
- 完善长音色名称的滚动展示，播放时显示音色波形反馈，暂停、加载或页面隐藏时停止动画。

### 四、本地导入与文件阅读

- 新增 PDF 导入，支持普通选择、ZIP 内文件和系统“使用简听阅读打开”。
- PDF 可选择漫画或电子书方式阅读，保留原页面布局与插图，支持翻页及进度恢复；不提供文字重排或朗读。
- PDF 自动识别模式默认以漫画导入，按每 50 页生成一节目录；支持最大 128 MiB、2000 页文件，转换后的页面图片合计上限为 512 MiB。
- PDF 转换逐页在后台处理并显示进度，遇到加密、损坏、超限或空间不足时明确提示，失败清理未完成书籍并保留用户原文件。
- 完善 EPUB 文字与漫画类型识别，支持可提取的正文内嵌图片。
- EPUB 内嵌图片保存到本地随书阅读，图片页参与翻页和位置恢复，文字朗读跳过图片标记，不读取远程正文图片。
- 改善 EPUB、HTML、MOBI 的原书目录识别与章节定位，减少目录错配和不必要的重复解析。
- 优化同一文件内多章节、目录锚点、中文编码路径及重复章节标识的处理，优先使用可用原目录，没有目录时再按标题或分段规则处理。
- 优化 EPUB 预览结果复用、正文提取、章节转换与写入，改善大文件和多文件导入效率。
- 完善导入进度、格式限制、空间不足及文件异常提示，失败时清理未完成产物。
- 优化系统文件打开、导入预览及入架流程，本地文件打开不触发启动自动播放。

### 五、搜索、书架与阅听记录

- 搜索支持按源自动获取后续页面，持续追加结果，无需反复点击加载更多。
- 后续页面与尚未完成首轮搜索的来源共用队列，优先让更多来源返回首轮结果；空页、重复页或失败时停止对应来源的翻页。
- 修改关键词或搜索条件会重置本轮结果，忽略旧请求的迟到回调，减少不同搜索结果混入的问题。
- 优化指定源多选、同名结果聚合、数量角标和结果类型筛选。
- 调整搜索列表／网格切换入口，改善窄屏布局及聚合弹层返回体验。
- 完善书架分组管理、批量整理与分组操作入口。
- 书架长按菜单将“封面与重命名”和“设置分组”分开，单本编辑与批量管理入口更清楚。
- 封面编辑支持本地图片、查找其他来源及图片链接预览，保存前可核对效果。
- 图片链接支持 HTTP／HTTPS 地址，预览成功后再保存；地址无效、加载失败或超时会保留原封面，取消编辑不提交变化。
- 优化书架书脊装饰、本地无封面书籍的默认封面和来源标签展示。
- 优化首页来源选择、分类入口、封面比例及榜单评分换算。
- 优化书架更新和阅读进度刷新，减少重复加载、封面闪动与无变化时的写入。
- 优化阅听记录列表刷新、行内操作按钮和滚动期间的数据更新，减少列表绘制开销。
- 优化底部 Tab 切换动画与横滑交互，默认启动页仅在冷启动生效，减少返回前台时意外切页。
- 外观设置支持选择横滑切换底部 Tab，或切换首页栏目／书架类型，保留顶部标签和底栏点击，减少横向手势冲突。

### 六、主题外观与简简陪伴

- 新增“纸感书房”“雾蓝”“墨山”主题套装，统一页面背景、默认封面、书封装饰和相关图标风格。
- 支持主题套装预览、应用、深浅色适配及选择记忆。
- 主题卡片可先查看局部效果再应用，预览时不改变当前全局外观；各套装保留独立风格与配色。
- 修复主题背景、书脊与封面装饰显示异常。
- 新增默认关闭的“简简陪伴”限时体验，可在外观设置中开启。
- 简简支持本地表情气泡、点击互动、待机动画和长按拖动；应用内切换页面时保持人物位置。
- 点击简简可轮换开心、害羞、惊喜、困倦、看书、比心等九种表情和本地文案；长按后拖动，松手停留，拖动时不误触气泡。
- 人物和气泡根据窗口边界调整位置，退后台暂停动画；关闭陪伴后立即移除人物，重启保留开关选择，人物位置重新回到默认位置。
- 优化底部弹层，支持通过顶部手柄调整高度。
- 目录、阅读与播放设置、换源、书架管理等弹层支持在不同高度间切换，较低高度下仍可滚动访问内容。
- 修复部分沉浸菜单显示及阅听统计胶囊外溢阴影问题。

### 七、书源、会员与使用引导

- 持续同步和完善书源运行内核，改善规则兼容、图片处理、音频解析、登录 Cookie 与缓存恢复。
- 优化书源异常隔离和任务取消，减少单个异常来源对其他任务的影响。
- 优化会员中心、套餐展示、购买恢复、订阅管理和权益对比说明。
- 会员页面集中展示免费与会员能力差异，明确 AI 处理、主题图标、主题套装、自动备份和搜索并发等权益；书源导入继续免费且不限数量。
- 优化设置页加载，减少会员状态查询造成的界面等待和草稿覆盖。
- 重整离线使用教程，增加快速入门、书源找书、阅读朗读、听书播放、书架记录、本地下载、备份设置及常见问题指引。
- 教程以入门主卡、六个主题入口和常见问题组织内容，支持进入分步详情，无网络时也可查看；在“我的”和关于页均可进入。
- 调整加载、空状态与错误提示，让反馈更清晰。

## 发布口径说明

- 当前漫画着色、漫画翻译和 AI 超分按会员权益校验，不沿用中间版本“免费开放着色”的旧公告。
- 会员搜索并发当前实际可设范围为 1–12，不使用“无限并发”的表述；默认图标、基础主题与手动云备份保留免费能力。
- 会员价格、优惠有效期以华为商品与实际收银台为准，本文不固定促销金额。
- 翻译效果取决于文字识别与模型，日／韩翻译采用中转；不承诺所有图片均能准确回填译文。
- PDF 不支持文字朗读；旧导入 EPUB 若需新增正文图片或重建目录，需要重新导入原文件。
- 最新工作区功能及不同设备适配尚有待验收项目，本文不代表所有功能均已完成实机验证。
