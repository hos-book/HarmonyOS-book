## 六、本轮实现与验收记录

- 页面 → 服务 → 存储：阅读设置复用 `TextReadingSettingsService`；书架展示覆盖及单本分组通过 `BookPresentation` / Preferences 保存；继续阅读位置与可关闭的历史快照分开；没有新增服务端接口或数据库。
- EPUB：新导入时提取章节内嵌图片，图片独占稳定页面；图片路径限定在书籍私有目录，单图 20 MiB、全书图片 128 MiB、单图 32MP。朗读跳过图片标记且保留原始字符坐标。旧版本已转换且未保留图片的章节需要重新导入原 EPUB；HTML/MOBI 正文图片与原始复杂排版仍不在本次支持范围。
- 选字使用系统选词菜单，小艺入口由设备系统提供，尚未完成小艺调用验收。连续正文、翻页和弹层之间的选字手势仍需长时间实测。
- 漫画加载展示实际等待秒数，不伪造百分比；超分只在 API 26 且具备对应能力时运行，有输入/输出预算和超时回退，超长图或不支持的图片保留原图。实际画质与返回帧率仍需同设备对比。
- 后台检测归服务持有，离开页面保持任务；复用 dataTransfer 长时任务与本地通知。拒绝通知时仍显示页内结果；系统取消或挂起时取消后续检测并保留已完成结果。系统杀进程后不承诺继续运行。
- 历史关闭后保留既有历史，停止新增搜索、播放、阅读历史及阅听时长；隐藏记录 Tab，继续保存必要的续播续读位置。重新开启后只从开启时继续记录。
- 分组采用单本单组，编辑面板可新增并归组；指定源未选择时沿用当前筛选范围，选定后只搜指定源；同名按内容类型与去空白、转小写后的书名聚合，同类型不同作者同名会聚合。
- 失效/重导源保留收藏、历史和续读引用书籍的目录与正文，详情刷新失败回退已有内容；手动编辑的书名封面高于规则元数据，主动点击“查找书源封面”才搜索替代封面。
