# 课本里的春天

这是一套为简听阅读制作的语文课本风格主题。米白纸页、朱红批注、青绿山水与钢笔线描共同呈现温润的课本记忆；四个 Tab 分别拥有独立背景，并配有浅色、深色两套视觉素材。

| Tab | 场景 | 视觉表达 |
| --- | --- | --- |
| 首页 | 春日学堂 | 学堂、远山与春日枝叶，作为阅读旅程的开篇 |
| 书架 | 书窗竹影 | 书窗、课本与竹影，呈现安静的藏书空间 |
| 记录 | 纸页钢笔 | 纸页、钢笔与笔记细节，承载阅读与聆听的积累 |
| 我的 | 庭院藏书 | 庭院与藏书章，营造个人书斋的归属感 |

插画沿画面边缘展开，中央保留文字与卡片的展示空间。页面采用独立的 `background.home`、`background.shelf`、`background.record`、`background.profile` 图片配置；通用背景复用首页场景。

| 色彩角色 | 浅色 | 深色 |
| --- | --- | --- |
| 纸张／页面底色 | 米白 `#F4EEDC` | 墨绿 `#232B28` |
| 主要文字 | 墨色 `#383A31` | 暖白 `#E8DFC7` |
| 主题强调色 | 朱红 `#A64635` | 柔朱红 `#D99178` |
| 植物与山水 | 灰绿 `#8EA398` | 灰青 `#879B8A` |

四个 Tab 的常态与选中态保持统一的画布和视觉中心。首页使用学堂，书架使用成排课本，记录使用钢笔笔记本，我的使用人物藏书章。选中态通过朱红色与局部填充表达。

书架与记录页的 23 项顶部按钮均提供浅深两套整按钮图片，图标、纸签底板与描边已合成为透明 PNG。搜索、筛选、分组及编辑等状态使用各自字段。五种功能图标采用同一套线条语言。

在线书、本地书与播放器分别拥有默认书封；书封保留标题空间，书名由 App 叠加。播放器使用独立的夜读场景，配合暗色蒙层让文字与控制按钮清晰呈现。材质选择“弱”，底栏采用常规样式。页面字体、页面排版及阅读器设置沿用 App。

交付目录包含：

- `课本里的春天.jttheme`：手机及主题制作器可导入的正式主题包。
- `theme-source/manifest.json`、`theme-source/theme.json`、`theme-source/assets/`：完整的主题编辑素材。
- `source/`：可编辑创作源文件；`vectors/` 保存 SVG 原稿，`build_artwork.py`、`build_icons.py`、`build_theme.py` 分别生成插画、图标和主题配置。
- `浅色预览.png`、`深色预览.png`：用于展示浅深配色、四页面场景与素材关系。
- `背景总览.png`：展示四个页面的完整插画。

主题依据 `THEME_AI_GUIDE.md` 的 `jianting.theme` 协议制作，`schemaVersion` 为 `1`，`baseThemeId` 为 `default`，浅色和深色各填写 135 项字段。复杂插画已栅格化为 PNG，简洁 Tab 与功能图标保留 SVG。包内所有图片均直接位于 `assets/` 目录。

手机导入步骤：

1. 将 `课本里的春天.jttheme` 保存到手机。
2. 打开简听阅读，进入“我的 → 主题与背景 → 套装 → 制作主题”。
3. 在“主题信息”中点击“导入主题”，选择该文件。
4. 切换浅色与深色预览，查看首页、书架、记录、我的及播放器。
5. 点击“保存并应用”。自制主题沿用 App 现有会员权益。

网页或 Windows 主题制作器也可通过“导入主题”继续编辑，调整后的主题可再次导出。

预览图属于设计展示；App 的原生材质、窗口裁剪、真实书封及控件布局以设备呈现为准。设备效果留待导入后查看。

继续创作与重新打包：

生成工具使用 Python、Pillow、numpy 与 resvg-py。预览字体采用 Windows 的宋体与微软雅黑。主题包使用已栅格化的图片，手机导入后直接读取包内素材。

在当前交付目录打开终端，执行以下命令可重建全部素材、预览图与主题包：

```powershell
python -m pip install pillow numpy resvg-py
python source/build.py
```

编辑 `theme-source` 内的配置或成品素材后，执行以下命令可直接重新打包：

```powershell
python source/build.py --pack-only
```

插画通过本地原创 SVG 绘制并栅格化，PNG 中已合入细微纸纹。源稿、主题素材与生成脚本一同保留，便于后续调整颜色与构图。
