# 樱之契约 · 百变小樱主题

这是一套为简听阅读制作的自制主题，方向取自百变小樱／库洛牌：星之杖、魔法阵、樱花与缎带。四个 Tab 各有一套独立主背景，浅色与深色分别绘制，不做同一张图反转。

主题 ID `custom-sakura-contract`，主题名“樱之契约”，协议 `jianting.theme` / `schemaVersion 1`，`baseThemeId` 为 `default`，浅色与深色各填满 135 项字段。

## Tab、图标与顶部按钮

- 底部 Tab 四组双态：首页星之杖、书架魔法书（封面星纹）、记录五瓣樱花、我的人像加星。常态为雾紫灰（浅色 `#A88A98`、深色 `#C6A8B8`），选中为樱粉填充加烫金细节；图标保留原色，文字由 `tab.normalColor` / `tab.selectedColor` 分别染色。
- “我的”没有使用缎带蝴蝶结：25 vp 下缎带容易被读成房子或领结，语义不明确；缎带只留在背景和账号卡里做装饰。
- 五种功能图标 `icon.Search`、`Filter`、`Grid`、`List`、`ChevronRight` 为单色透明 PNG，浅色用深梅墨、深色用粉白。
- 23 项顶部整按钮浅深各一套，全部提供：常态是奶油半透明圆盘加玫瑰细描边，激活态（搜索展开、已选分组、内容已筛选）是樱粉实心圆盘加烫金描边与奶油图形。书房分组的添加、展开、收起、关闭和记录的返回、摘录、历史、编辑、完成、锁定都单独绘制，不靠系统符号兜底。

## 默认书封

在线书、本地书共用同一套书封素材（`cover-light.webp`、`cover-dark.webp`，900×1200），播放器封面用方形播放素材。构图为下部三分之一画星之杖与半圆魔法阵，上部三分之二留干净底色，正好落在本地封面 22%–54% 的书名区与 66%–80% 的作者区。书名色浅色 `#5A3145`、深色 `#FFF1F6`；作者叠底色 `#CCFDF1F3` / `#CC2A1522`，长书名或跨行文字压到花瓣上也还能读。`cover.illustratedPlaceholder` 为 `true`，书封装饰选 `0` 简洁，不加边框与书脊，避免盖住烫金细线。

## 素材与制作

14 张插画由 Seedream 5.5 生成：先出 7 张浅色（四页面 + 播放器 + 书封 + 账号卡），再用同构图图生图得到 7 张深色版本，日夜场景一一对应。提示统一要求无文字、无字母、无 logo、无人物、无水印，中部留空。

| 用途 | 尺寸 | 格式 |
| --- | --- | --- |
| 页面背景 | 900×1950 | WebP q86 |
| 播放器背景 | 900×900 | WebP q86 |
| 默认书封 | 900×1200 | WebP q86 |
| 账号卡 | 1400×700 | WebP q86 |
| Tab 图标 | 128×128 | 透明 PNG |
| 功能图标 | 96×96 | 透明 PNG |
| 顶部整按钮 | 144×144 | 透明 PNG |

图标与按钮用 Pillow 程序化绘制：4 倍超采样后缩回目标尺寸，圆形底板单独合成再叠图形，避免半透明填充被直接写入像素；线条统一圆头端点。84 个素材保持同一描边粗细与视觉中心，改色可以整批重出。材质选择“均衡”（`materialStyle` 3），底栏为常规样式（`verticalBottomTabs` false）。

## 交付目录

- `樱之契约.jttheme`：可直接导入的正式主题包（2.3 MB，84 个素材）。
- `theme-source/manifest.json`、`theme-source/theme.json`、`theme-source/assets/`：完整主题素材与配置，可在三端制作器继续编辑。
- `浅色预览.jpg`、`深色预览.jpg`：浅深配色、四页面与播放器的组合预览。
- `背景总览.jpg`：四页面浅深八张完整插画。

## 导入步骤

1. 把 `樱之契约.jttheme` 保存到手机。
2. 打开简听阅读，进入“我的 → 主题与背景 → 套装 → 制作主题”。
3. 在“主题信息”点“导入主题”，选择该文件。
4. 切换浅深预览，按需微调素材位置、缩放、蒙层与配色，点“保存并应用”。

网页与 Windows 制作器可点“导入主题”直接打开同一文件，切换浅深预览查看首页、书架、记录、我的与播放器。

## 验证边界

结构校验覆盖：浅深各 135 个字段、键不重复不缺失、`range` 取值为整数且在范围内、`select` 取值命中枚举、颜色以 `#` 开头、所有 `assets/` 引用都在包内、没有孤立素材、`manifest.json` 格式与版本正确。以上全部通过。
